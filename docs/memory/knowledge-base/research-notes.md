## OpenClaw
- Telegram group allowlist format: `"groups": { "<chat_id>": { "requireMention": bool } }`
- Do NOT use `allowlistedChats` — that's the wrong key
- Always read the actual config file before suggesting edits (learned the hard way day 1)
- Skills can be installed from ClawHub via `clawhub` CLI
